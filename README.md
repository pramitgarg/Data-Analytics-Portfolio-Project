# Project Overview: Indian Telecom Customer Churn Analysis
The objective of this project is to perform an in-depth analysis of customer data from Indian telecom service providers to identify key factors contributing to customer churn. By examining demographic details and usage patterns, the goal is to derive actionable insights that can inform business strategies aimed at improving customer retention.

# Key Business Questions Addressed:

**Churn Distribution**: What is the churn rate across different telecom operators?

**Demographic Influence**: How do customer attributes such as age, gender, and location impact churn behavior?

**Usage Behavior**: Is there a relationship between higher data usage or call volumes and reduced churn?

**Income Correlation**: Does estimated salary show any significant correlation with churn?

**Predictive Modeling**: Can we build a reliable model to predict churn based on customer demographics and service usage?

**Data Quality Assessment**: Are there anomalies or data integrity issues (e.g., negative values in calls_made, sms_sent, or data_used) that may affect the analysis?

**Geographic Trends**: Which states or cities exhibit the highest churn rates, and what patterns can be observed geographically?

This project not only aims to uncover patterns in churn behavior but also to demonstrate how data-driven decisions can help telecom companies minimize customer loss and optimize user engagement strategies.
